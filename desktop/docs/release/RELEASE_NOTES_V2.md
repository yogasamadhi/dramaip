# DramaIP v2.0.0 版本说明

> 历史范围：本文是 v2 候选阶段的版本说明与目标发布边界，不确认 v2 已正式发布，也不定义当前 v3 能力。现行文案以 [产品定位](../../../docs/product/POSITIONING.md) 为准：小说可独立形成稿件/投稿成果，改编与剧本是转化核心，媒体是可选生产出口；当次状态见 [发布检查清单](./RELEASE.md)。

v2 记录的离线样片体验：无账号、无 API Key、无网络时，可以直接打开内置虚构样片，完成候选比较、影响检查、离线审片和标准媒体交付。这不是离线 AI 小说、图片、音频或视频生成能力。

## 主要变化

- 导演工作台集中呈现镜头导航、主预览、角色与场景参考锁、候选比较、素材覆盖、Animatic、审片和交付状态。
- 生产影响图贯穿故事、资产、镜头、生成结果、审片包和交付；未解决的关键影响会阻断最终交付，带理由的豁免保留审计记录。
- Retake 生成不可变候选并保留 Prompt 快照、输入指纹、成本和血缘；只有采用操作会产生新资产版本并传播影响。
- 图片生成、图片编辑、TTS 和视频 Provider 使用显式能力、数据政策和路由策略；最终模式不进行未授权并行生成或自动跨 Provider 兜底。
- 所有套餐支持免登录离线审片包；Studio 增加 5 席团队与 5 GB、最长 30 天的云审片。
- Creator 及以上支持 FCPXML 1.10、CMX 3600 EDL、SRT 和统一媒体清单；无法由 EDL 表达的内容会出现在损失报告中。
- 套餐更新为 Free、Creator、Studio、Enterprise，图片、音频和视频默认 BYOK。本地项目无限且不会因订阅到期被锁定或删除。

## 当时的目标平台支持

- macOS 与 Windows：目标为 v2.0.0 GA，必须通过签名、安装、升级和回滚门禁后发布；本条不确认已发布。
- Linux：同版本 Beta，AppImage 与 deb 完成 smoke 后发布。

## 隐私与数据边界

产品分析默认关闭，明确同意后仅上报随机安装标识、版本、操作系统、白名单事件、耗时区间和标准错误码。云审片只上传用户主动选择的 manifest、低清代理、缩略图和评论；小说、Prompt、API Key、源素材和母版不会进入审片服务。

正式发布状态以 Bun 1.4.0 完整质量门、Electron E2E、`package`、`release:metadata` 和受管发布审批为准。任何真实 Provider、剪辑器导入、签名、公证、支付或对象存储证据缺失时，本版本保持 RC。
