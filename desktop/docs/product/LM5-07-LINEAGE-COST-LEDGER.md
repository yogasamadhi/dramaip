# LM5-07：生产谱系、能力快照与成本账本

本轮把视频生成从“任务已提交”提升为可追溯的本地生产记录。数据模型同时适用于后续的图片、音频与渲染任务。

## 用户可见行为

- 每次新视频提交都会冻结源实体及其更新时间、Provider 名称/类型、模型、当时能力状态、默认参数、Prompt、负面 Prompt、seed 和引用资产。
- 快照明确不保存 API Key、Provider 原始响应或媒体二进制；凭据仍只留在系统 Keychain。
- 重试会创建新的谱系，关联父谱系/重试来源，不会覆盖旧任务、旧参数或旧结果。
- 用户在视频候选中采用最佳结果时，谱系记录会标明当前采用的结果；同一源实体再次采用会清除旧采用指针。
- 项目概览提供本地费用账本：有报价时显示“本地估算”，没有报价时显示“未知”；可手工回填实际费用，且不会覆盖原始估算。
- 项目包升级到 v7，携带脱敏谱系和费用记录。导入新项目时不伪造可轮询的旧任务，只保留来源关系和导入前任务 id 的说明。

## 旧项目兼容

迁移会为旧视频任务创建兼容谱系：已有 Provider、模型、Prompt 和关联镜头会被保留；没有记录的源版本、seed、能力快照、引用权重、估算和实际账单显式标为 `partial` 或 `unknown`，不会猜测或补零。

## 验证

- 数据库迁移回放覆盖旧视频任务回填、可重入迁移和事务回滚。
- 视频服务测试覆盖不含凭据的能力快照、seed、参数、引用和估算费用。
- 项目包往返覆盖谱系、估算/实际费用分离与外键重映射。
- 完整单测、DB smoke、Desktop 类型检查、构建、E2E 与 UI baseline 均通过。
