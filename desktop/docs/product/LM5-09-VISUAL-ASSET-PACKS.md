# LM5-09：版本化角色与场景生产资产包

> 阶段记录：本文保留 LM5-09 的资产包实现和验证边界。视觉资产是 [产品定位](../../../docs/product/POSITIONING.md) 中可复用的生产出口，服务已采用故事/剧本；它不取代小说、叙事质量或改编核心，也不是小说稿件/投稿的必备成果。下文历史包格式与限制不替代现行代码或发布说明。

本轮把“人物视觉档案 / 场景视觉设定”从一段描述文字升级为可复用、可审计的生产资产包。它面向本地人工制作或已获授权的素材，不依赖图片生成渠道。

## 用户操作

1. 先在“视觉档案”创建角色，或在“视觉设定”创建场景。
2. 在项目概览的“角色 / 场景生产资产包”选择归属和槽位，导入本地参考素材或选用已有资产。
3. 创建候选版本，填写服装阶段、道具点位、负面约束或裁剪/标注说明；源文件不会被应用复制、修改或删除。需要真正裁剪/标注时，在外部工具另存为新文件后作为新候选导入。
4. 经权利台账核验后，手动“采用此版本”。采用新版本只替换未来默认选择，绝不覆盖历史版本。
5. 在分镜的“素材”Inspector，为角色、服装、场景、风格、道具或声音锁定精确版本。

## 一致性与风险规则

- 角色的脸部锚点、全身/三视图、表情、服装阶段、声音参考，以及场景的布局、昼夜/天气、布光/色彩和关键道具点位，会显示是否已有采用版本。
- 采用同一槽位的新版本时，指向旧版本的分镜锁只被标记为“待确认更新”；旧镜头仍然保留原版本和原因，用户必须手动替换。
- 资产包根据设定文字提示群演/人群、儿童、动物、历史服化道等高制作风险；提示不是自动生成或排期承诺。
- 本地素材仍需在“版权与授权台账”完成用途核验；资产包不会绕过参考资产的权利限制。

## 项目包与边界

- 含资产清单导出的 `.sdnspkg` 会携带资产版本、采用状态与分镜锁的结构化关联；不携带本地媒体二进制。
- 在新机器导入后，本地文件仍可能显示为 `missing`，但版本身份、历史锁和 stale 原因会保留，避免静默换图。
- 不提供未授权真人相似度、演员复刻、LoRA 训练或自动图像编辑能力。
