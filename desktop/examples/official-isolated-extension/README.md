# Official isolated extension fixture

This fixture is compiled by `extension:pack` and exercised by Public Plugin API and Extension Host conformance tests. It contains no Node, filesystem, network, Electron, SQLite, React or HTML dependency.

This is technical conformance evidence, not a shipped creative feature or a new market positioning. Extensions support the author-controlled novel and adaptation workflows defined in [product positioning](../../../docs/product/POSITIONING.md); they do not own authoritative project content or imply unrestricted third-party UI support.
