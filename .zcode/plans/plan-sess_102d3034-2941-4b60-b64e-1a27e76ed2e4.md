# UX 与功能完整度全量优化执行计划

依据项目 LOOPRULE 编写，把 19 项审计问题拆成 **8 个阶段（Phase 0～7）**，每阶段含若干 loop，逐个提交、验证、合并、推送。

## 问题 → Phase 映射

| Phase | 目标 | 含问题 # |
|-------|------|---------|
| **Phase 0** | 全局布局基建（RootLayout + GlobalRail 全局化） | #4 |
| **Phase 1** | 性能（chapterWorkflowKey 解耦 + 按章加载） | #13 #8 |
| **Phase 2** | 导航架构（统一导航组件 + 收敛分组 + 章节模式保留入口） | #1 #2 #3 |
| **Phase 3** | 状态收敛（contextControls 共享 store + workflow 数据拆 store） | #5 #15 |
| **Phase 4** | 健壮性（AI 重试 + 离线检测 + IPC catch + 流式兜底） | #9 #10 #11 #12 |
| **Phase 5** | 交互安全（草稿恢复确认 + 卡片 CTA + 视频虚标） | #7 #6 #16 |
| **Phase 6** | 虚拟化 | #14 |
| **Phase 7** | 无障碍与组件一致性 | #17 #18 #19 |

## 依赖关系
- Phase 0 和 Phase 1 无互相依赖，可最先做（任选先后或并行）
- Phase 2 依赖 Phase 0（RootLayout）
- Phase 3 依赖 Phase 0 基建（store 模式）
- Phase 6 依赖 Phase 3（数据已收敛到 store）
- Phase 4/5/7 相对独立

## 各 Phase 核心内容

### Phase 0：全局 RootLayout
- 新建 `RootLayout.tsx`（GlobalRail + Outlet + TaskDock），用 React Router layout route 包裹所有路由
- 从 WorkspaceShell/ProductionWorkspaceShell 移除内部 GlobalRail
- 修正 GlobalRail 激活态判断（/settings/tasks 应高亮设置）
- **效果**：项目列表/设置/创建页自动获得左侧栏和主题切换

### Phase 1：性能（最痛的 P0）
- **Loop 1-A**：`chapterWorkflowKey` 拆为 `chapterMetaKey`（去掉 content），打字不再触发 14+ IPC
- **Loop 1-B**：8 个章节级 Section 改为 ByChapter 加载（补齐后端 IPC：chapterMemory/highlight/evaluation/feasibility/storyEvent/foreshadowing/characterState），切换章节时正确刷新

### Phase 2：导航重构
- **Loop 2-A**：抽取 `WorkspaceNav` 组件（消除 3 处重复 map），重新分组（创作核心/设定素材/记忆一致性/诊断/改编准备/记录）
- **Loop 2-B**：章节模式上下文侧栏改为上下分区（章节树 + 紧凑导航），不再吞掉项目导航

### Phase 3：状态收敛
- **Loop 3-A**：`contextControls` 提到 `useAiContextStore`，3 份独立状态合一，任一入口调整全局可见
- **Loop 3-B**：workflow 数据态拆到 `useWorkflowSnapshotStore`，WorkspacePage 28+ useState 收敛

### Phase 4：健壮性（4 个独立 loop）
- **4-A**：封装 `toastAiError(msg, retry?)`，AI 失败加重试按钮 + 中文错误码
- **4-B**：RootLayout 加 online/offline 监听，断网 banner + AI 按钮灰化
- **4-C**：VideoGenerationPage 补 catch；ChapterEditor 流式加 5 分钟超时兜底

### Phase 5：交互安全（3 个独立 loop）
- **5-A**：草稿恢复改弹确认 Dialog（含预览），不再无声覆盖
- **5-B**：项目卡片 CTA 简化为单主按钮
- **5-C**：4 个未实现视频平台标记「即将支持」并禁用

### Phase 6：虚拟化
- 引入 @tanstack/react-virtual，改造项目列表/AI记录表/灵感卡网格

### Phase 7：无障碍与一致性（2 个独立 loop）
- **7-A**：列表卡片改 article/role 可键盘聚焦；Dialog 焦点还原；加 `?` 快捷键面板
- **7-B**：抽取 SectionHeader + EmptyState + PageLoader 共享组件

## 执行约束
- 每个 loop 独立分支 `loop/ux-{phase}-{label}`，完成后合并推送
- 逐 loop 推进，禁止批量
- 每个 loop 完成后跑 `tsc --noEmit`（涉及 DB 加 `pnpm test:db`）
- 每个 loop 的 diff 聚焦单一目标
