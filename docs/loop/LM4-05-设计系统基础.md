# LM4-05：视觉、主题、密度、动效与无障碍基础

状态：本地实现和回归通过，待按 Loop 流程合并、推送并登记完成记录。

## 交付

- 在 `globals.css` 和 Tailwind 中建立兼容既有 class 的语义 token：`canvas`、`surface`、`brand`、`ai`、`success`、`warn`、`block`，并保留 `background/card/primary` 等旧 token alias。暗色主题不再使用接近纯黑的表面，边界、正文、静默文字和输入焦点均有独立对比层级。
- `ThemeProvider` 支持 `light`、`dark`、`system` 三态；`system` 保留为用户偏好并监听系统外观变化。旧的 `sdns-ui-theme` 会兼容读取，新偏好、密度和编辑字体分别持久化在本机 localStorage。
- 新增“外观与编辑偏好”设置页：可选择主题、舒适/紧凑密度、叙事衬线/无衬线/等宽正文；偏好不会改变项目数据。章节 TipTap 正文读取编辑字体 token，保持 16px 以上的可读正文。
- 基础 Button/Input/Textarea/Select/Card/Dialog/Sheet/Toast 改用共享高度、半径、surface 和焦点环；Button 会用显式 `title` 补足图标按钮名称。Dialog/Sheet/互动卡片加入克制的进入、hover 和层级动效。
- 建立 `studio-page-enter`、`studio-rise-in`、`studio-skeleton`、`studio-ai-pulse` 与状态 surface 工具；`prefers-reduced-motion: reduce` 统一将动画与过渡静态化，避免以动效承担状态表达。
- UI 基线扩展为 7 个 fixture：保留 light/dark、1024/1320/1600、失败视频和 reduced-motion，并新增“跟随系统（解析为明亮）”的外观页。报告记录实际 `themePreference` 和 `density`，可复验偏好组合。

## 无障碍与人工复核

- 基础焦点改为高可见的双像素 ring 与背景 offset；工作台导航使用 12px 以上分组文字，非激活导航和键盘焦点明确可见。
- 为原有基线中的章节标题、章节选择、编辑器、返回/设置和视频集数控件补充可访问名称。7 个固定 UI fixture 的 Chromium AX 扫描从 13 项无名称控件降为 0 项。
- 人工检查了暗色 1320px 工作台、system 主题外观页以及紧凑 + reduced-motion 视频失败页：暗色表面仍可区分导航、编辑区与 AI Inspector；系统偏好和密度选择可见；失败、成功和“最佳”结果没有依赖动画才能理解。
