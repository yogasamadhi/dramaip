状态：已通过本地验收，待按 Loop 流程合并、推送并登记完成记录。

## 已交付

- `quality_gate_reports` 新增可选 `source_fingerprint`（migration 19）。新质量闸门以实际阶段的项目、分集、剧本/场景或镜头内容生成稳定指纹；历史报告保留原样读取，但不再被当作当前通过或阻塞真值。
- 项目概览、改编就绪检查、创意诊断和质量闸门页复用同一项目质量真值：只采用同一项目、同一阶段、同一目标且源指纹匹配的最新报告。旧失败报告不会覆盖新通过结果；源内容改变后明确显示“报告已过期”。
- 视频阶段要求至少一个 `success` 视频任务关联一个具有本地或远端可用地址的结果。只有 pending、failed/canceled，或“成功但没有结果”都不会把阶段标为完成。
- 工作流快照会加载视频结果；章节正文变更直接参与工作流刷新键，避免正文已变而概览仍显示旧质量状态。
- UI 基线新增 `workflow-stale-quality-1320-light`：隔离 fixture 在生成通过报告后修改正文，确认 1320px 概览显示过期状态；同套 fixture 继续覆盖空状态、当前报告和视频成功/失败组合。

## 兼容与边界

- 旧质量报告没有源指纹时显示为“历史报告未记录源版本，请重新检查”；不会删除历史，也不会继续阻塞新内容。
- 指纹用于业务新鲜度判断，不是安全散列、签名或内容加密。
- 本轮不重设计质量闸门页面、不改变当前改编选择器；修稿采用的原子事务由 LM4-13 收口。
