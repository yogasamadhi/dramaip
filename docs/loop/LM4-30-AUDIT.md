# LM4-30 加密快照审计

状态：`partial`

已建立客户端快照信封：AES-256-GCM、32 字节恢复密钥、96 位随机 nonce、固定版本 AAD 与内容摘要。恢复密钥只能在 Electron 主进程中生成；该模块没有网络代码、日志代码或 Keychain 持久化代码，因此不会把密钥或项目正文暴露给 renderer、BFF 或遥测。

已通过确定性向量、错误密钥和密文篡改测试。错误密钥与篡改返回同一失败语义，避免形成认证 oracle。

尚未交付上传、下载、列表、删除、恢复 UI 或生产存储。仓库没有独立 Snapshot 领域服务/密文对象存储，且没有可用于生产的对象存储、KMS 或 LM3-34 灾备准入证据。不得把加密前项目包、恢复密钥或静态存储凭据塞进现有 Desktop BFF 作为替代。
