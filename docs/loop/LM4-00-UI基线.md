# LM4-00：UI、无障碍与状态基线

状态：已通过本地验收，待按 Loop 流程合并、推送并登记完成记录。

本记录为 Desktop 后续 UI/交互改造提供可重复的本地基线。它使用临时 userData 数据库，不读取真实项目、模型凭据、云端令牌或个人文件路径。

## 运行方式

```bash
cd dramaip-desktop
pnpm test:ui
```

开发时已构建可使用：

```bash
cd dramaip-desktop
pnpm test:ui:skip-build -- --output=artifacts/ui-baseline --keep
```

默认运行结束会清理临时目录；传入 `--output` 可保留截图与 `ui-baseline-report.json`，而 `artifacts/` 被 Git 忽略，避免将机器相关截图误提交。

## 无障碍判定

基线会通过 Chromium `Accessibility.getFullAXTree` 记录未被忽略的 button/link/textbox/combobox/checkbox/radio 是否缺少可访问名称。LM4-00 只建立观察基线：现有问题会在报告中保留，不以“零问题”掩盖现状；LM4-19 再把高频问题转为阻断性门禁。

## 初始观测（2026-07-19）

- `pnpm test:ui` 已生成 5 张页面状态截图，并覆盖项目列表、1024/1320 工作台、1600 剧本工作台和 reduced-motion 视频失败状态。
- 1024 宽度下，左侧导航、中心编辑区和右侧 AI 面板同时存在，中心可用编辑空间明显受限；这成为 LM4-06/07 响应式 App Shell 的回归参照。
- 可访问性树共报告 11 项无名称控件：工作台浅/深色各 4 项、剧本工作台 1 项、视频页 2 项；项目列表为 0 项。报告保留控件角色以供 LM4-19 逐项消除。
- 键盘焦点候选序列和各页面完整路由、视口、主题、动效偏好都保存在运行时 `ui-baseline-report.json`；没有使用真实项目正文、凭据或个人路径。

## 已知限制

- 当前界面的日期格式由运行时生成，截图用于状态与布局回归，不作为逐像素快照。
- 基线只模拟 `prefers-reduced-motion`；减弱动效的产品实现与验证属于 LM4-19。
- 小说工作台的截图以工作台壳层、章节选择和右侧 AI 操作区为准；富文本编辑器独立懒加载，完整编辑器状态由后续编辑器专项回归补齐。
- 该入口不执行真实模型或视频请求，失败状态由本地 fixture 构造。
