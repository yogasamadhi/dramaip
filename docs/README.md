## 阅读与事实边界

| 文档类型                          | 回答的问题                   | 使用边界                  |
| --------------------------------- | ---------------------------- | ------------------------- |
| POSITIONING / BRAND               | 为谁服务、核心取舍和统一表达 | 不是功能完成证明          |
| PLAN / 当前路线优先级             | 接下来做什么、如何验收       | 未勾选任务仍为计划        |
| 当前工程架构 / 用户指南           | 当前如何实现和使用           | 以代码及明确验证范围为准  |
| 带日期审计 / 旧版本设计与发布记录 | 当时发现、实现或验证了什么   | 不重写历史，不外推当前 GA |
