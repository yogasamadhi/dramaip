> 文档状态：in-progress / UX Execution Record
>

## 1. 背景与目标

此前的界面审阅发现：

- 项目内导航最多 5 层；同一页面在侧边栏、面包屑、标题里叫法不一致。
- 主流程看不到进度，AI 面板里约 13 个同权重按钮。
- 确认弹窗、勾选框和"不代表／不证明"类免责措辞密集。
- 品牌色同时用作链接色和警告色，还有 10–11px 小字。

本轮目标：在不改变数据语义的前提下，做到导航不超过三层、每屏一个主操作、可见的流水线进度、使用用户术语、有语义的设计系统。

## 4. 设计规则（后续页面必须遵守）

1. **每屏一个主按钮**：只有 `Button variant="primary"` 使用品牌色实心样式，其余操作用 secondary 或 ghost。
2. **导航不超过三层**：全局导航 → 项目内五项 → 页内阶段（`StageNavigation`）。新增功能放进现有阶段或"更多工具"，不再加侧边栏项。
3. **语义色**：
   - 品牌色只用于品牌标识和 AI 主操作；
   - 链接用 `text-link`；
   - 警告和错误用 `warning*`／`danger*`；
   - 禁用原生 Tailwind 的 `amber-*`、`red-*`、`emerald-*`、`green-*`，由 `lm7-ui.test` 守卫。
4. **最小字号 12px**：禁用 `text-[10px]`、`text-[11px]`，由 `lm7-ui.test` 守卫。
5. **进度可见**：多步流程用 `PipelineStepper` 呈现 gate，第一个未就绪的步骤即"当前步骤"。
6. **说明折叠**：不能指导用户行动的统计口径和免责说明放进 `Disclosure`，正文只保留可行动的提示。
7. **确认分级**：
   - 可恢复的操作：不弹确认，改为 Toast 加"撤销"，或在结果里说明已另存的检查点。
   - 覆盖定稿、产生费用、永久删除的操作：保留一个确认弹窗，写明影响。
   - Runtime 契约要求的权利／媒体声明勾选：语义不变。

## 5. 偏差与已知遗留

- **原生控件**：`<select>` 已全部迁移并由守卫禁止回退。`<details>` 没有逐个改成 `Disclosure`，改由全局 CSS 统一样式，对应守卫未打开。
- **当前制作对象**：保留行内 `<details>`，没有用 Drawer，因为 E2E 读取的是其中的原生 select。
- **助手入口**：放在顶部带文字的按钮，不在侧边栏。
- **章节目录按钮**：仍常驻工具栏，因为 E2E 依赖它可见。
- **创作分析预选**：有正文时只预选、不自动确认，保留"不隐式读正文"的约束；超过 12 章时只预选范围，每章表达仍需用户选择。
- **项目网格卡片**：不显示每个项目的驾驶舱进度。逐卡读取完整证据的成本过高，卡片已显示下一步；以后可由 Runtime 提供汇总读模型后再加。
- **确认分级**：只覆盖了上面 4 个可恢复动作，其余 `confirmDialog` 调用保留（涉及费用、永久删除、契约声明）。
- **免责措辞**：页内"不代表／不证明／不认证"类表述仍约 110 处，只有数据洞察页做了折叠。
- **"待确认"导航时有时无**：已排查，该项由 automation bundle 确定性贡献，所有完整 Profile 都包含它，不是 bug。截图中的差异来自旧视觉基线。
- **视觉基线**：只更新 darwin，`tests/electron/*-snapshots/*-win32.png` 需要在 Windows 上重新生成。

## 6. 产品侧后续路线（未实施）

1. **用户验证**（最高优先级，M5 目前 0/6）：
   - 招募 5–8 名网文作者和短剧编剧做任务式可用性测试，任务为：首章 → 采用 → 下一章；导入小说 → 改编诊断 → 第 1 集剧本。
   - 与火山剧创、小云雀、万兴剧厂做盲评对照。
   - 记录完成率、首个成果用时和放弃点。
2. **首发楔子**：先只主推一条路径（"网文作者把连载改成短剧剧本"），其余路径放在示例和更多工具里。
3. **付费意愿**：先验证"按项目或按月"的本地版订阅，以及自带模型密钥与托管额度的价格敏感度。权益草案见 [COMMERCIAL_ENTITLEMENTS_DRAFT](./COMMERCIAL_ENTITLEMENTS_DRAFT.md)。
4. **可选匿名遥测**：默认关闭，用户明确开启后只上报漏斗事件（不含正文和提示词），用来回答第 1 项的指标问题。
5. **导出对接**：剧本／分镜按火山剧创、小云雀、万兴剧厂、剪映草稿的导入格式输出，优先剪映草稿和通用 FDX／Fountain。
6. **AI 合规溯源包**：利用已有的版本链和来源冻结，导出"人工创作比例／AI 参与环节／来源"说明，用于平台送审和版权登记。
7. **媒体深度**：在用户验证证明剧本价值之前，不扩大媒体生成投入。
