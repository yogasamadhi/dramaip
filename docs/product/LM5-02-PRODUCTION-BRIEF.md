# LM5-02 三种创建路径与项目生产简报

每个项目都会保存一份可编辑的生产简报，而不是把“章节数、集数和两分钟时长”当作不可修改的
换算规则。简报包含：创建目标、表现形式、目标平台与地区、画幅、单集时长范围、试播集数和预算档位。

- **从灵感写小说**：创建小说项目，下一步补全故事设定或章节。
- **导入已有小说 / IP**：只创建受权项目和生产目标，不会先生成空章节；下一步应导入用户拥有权利的正文或剧本。
- **直接制作漫剧**：创建项目后直接进入第一季设置；不要求先有小说章节。

所有 Profile 值都是建议，用户可在创建时修改。项目会保存当时的选择并随项目包往返；旧项目在读取时得到
兼容 Profile，但不会修改既有章节、季、集数或单集时长。

正文/剧本文件解析仍属于后续导入流程；在此之前，界面会明确提示“待导入”，不会伪造已经导入的内容。
