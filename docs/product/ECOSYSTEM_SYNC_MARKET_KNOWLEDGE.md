# 云同步、资源市场与知识库路线设计

本文只定义后续生态能力的产品边界和架构路线，不代表当前版本已经实现云同步、资源市场、公共知识库或语义搜索。

## 1. 目标

后续生态能力必须在不破坏本地优先原则的前提下扩展：

- 云同步：让用户可选择把轻量草稿、项目包或资产索引同步到自己的账号。
- 资源市场：让创作模板、项目级 Skills、Agent 方案和提示词包可被审核、购买、分享或私有分发。
- 知识库：让用户把自己的资料、样本抽象结构、项目文档和创作规范纳入可解释检索。

这些能力不能改变当前桌面端的核心事实：本地 SQLite 项目仍是可信写入源，任何云端能力都必须显式开启、可导出、可关闭、可恢复。

## 2. 不进入当前实现范围

LM2-22 不新增代码、数据库迁移、账号体系、支付接口、云存储 SDK、远程搜索服务或市场页面。

以下能力进入后续 loop 或独立产品里程碑：

- 实时多人协作和 CRDT 文本编辑。
- 自动把用户正文、样本原文或诊断包上传到云端。
- 公共资源市场的结算、税务、分成和退款。
- 云端训练、模型微调或跨用户数据学习。
- 未经用户确认的云端语义搜索、公开发布或素材推荐。

## 3. 数据边界

| 数据类别 | 默认位置 | 可否同步 | 同步粒度 | 规则 |
| --- | --- | --- | --- | --- |
| 项目元数据 | 本地 SQLite | 可选 | 项目标题、类型、目标受众、更新时间 | 用户开启项目同步后才上传 |
| 正文章节/剧本 | 本地 SQLite | 可选但高风险 | 版本快照或项目包，不做静默字段覆盖 | 必须加密传输和存储，冲突进入人工队列 |
| 移动灵感 | 本地导入或移动草稿箱 | 可选 | 灵感卡片 JSON/Markdown | 可作为最小同步试点，不写正文 |
| 项目资产 | 本地文件或远端 URL | 可选 | 资产清单优先，二进制单独授权 | 默认只同步引用和校验信息 |
| 模型密钥 | 本地安全存储 | 不同步 | 无 | 任何账号同步都不得上传 API Key |
| 样本文档原文 | 本地临时导入 | 默认不同步 | 抽象结构卡片可同步 | 不把第三方原文作为市场资源或公共知识库内容 |
| 诊断包/日志 | 本地导出 | 默认不同步 | 用户手动生成的脱敏包 | 必须沿用现有脱敏策略 |
| 市场资源 | 云端资源库 | 可下载 | 模板、Skills、Agent 方案、提示词包 | 必须附带来源、许可、版本和审核状态 |
| 知识库索引 | 本地优先 | 可选 | chunk 元数据、embedding、来源引用 | 每条检索结果必须可追溯来源 |

同步系统的最小单位不应是“整个数据库文件”。推荐使用项目包、资源清单和待同步变更队列组合，避免远端覆盖本地数据库。

## 4. 隐私与安全

生态能力必须满足以下约束：

1. 显式开启：每个项目、每类数据、每个资源市场发布动作都需要用户确认。
2. 最小上传：默认只上传索引、摘要、抽象卡片和资源清单；正文和二进制资产需要单独授权。
3. 密钥隔离：模型 API Key、视频平台密钥和本地加密材料不得随账号同步。
4. 加密边界：传输使用 HTTPS；服务端存储正文类内容时必须支持加密字段或用户私有空间。
5. 脱敏复用：诊断包、日志、AI run 输入输出和样本文档继续复用既有脱敏策略。
6. 可删除：用户必须能删除云端项目快照、移动草稿、知识库索引和市场草稿。
7. 可审计：每次同步、发布、下载、检索都应生成本地可读记录，不记录密钥或完整敏感正文。

## 5. 冲突处理

云同步应采用本地优先、人工确认的冲突策略。

| 冲突类型 | 自动处理 | 人工处理 |
| --- | --- | --- |
| 项目元数据字段不同 | 可按更新时间合并非正文短字段 | 标题、题材、核心卖点冲突时提示用户选择 |
| 灵感卡片重复 | 按稳定 `cardKey` upsert | 同名不同内容保留两条并提示合并 |
| 章节正文/剧本文本不同 | 不自动覆盖 | 生成两个版本快照，使用 diff 预览采用 |
| 资产路径不同 | 保留本地路径，远端路径降级为引用 | 缺失二进制时提示重新定位或跳过 |
| 知识库索引过期 | 可重建索引 | 源文件缺失或权限变化时停止检索 |
| 市场资源版本不同 | 下载新版本为候选 | 已绑定项目的资源升级需用户确认 |

推荐实现一个 `sync_conflicts` 或等价队列，存储冲突对象、来源版本、远端版本、本地版本、建议动作和用户最终选择。任何正文级冲突不得静默覆盖当前工作区内容。

## 6. 资源市场路线

资源市场优先服务“可复用创作方案”，而不是售卖用户正文或样本原文。

第一批可市场化资源：

- 创作模板：项目设定、章节生成、拆书结构、短剧提案、分镜 Prompt 模板。
- 项目级 Skills：类型节奏、人物对白、镜头 Prompt、平台交付规范。
- Agent 方案：编剧室角色组合、主 Agent、模型绑定建议。
- 类型预设：题材、受众、爽点、反转、视觉风格和风险提示。
- 导出包格式：投稿包、短剧提案包、分镜交付包的格式规范。

审核要求：

- 不得包含第三方小说原文、影视台词、真人肖像素材、未授权声音/角色模仿说明。
- 不得承诺绕过平台检测、规避审查或隐藏来源。
- 必须声明作者、许可、适用版本、适用题材、风险边界和示例输入输出。
- 市场资源下载后应作为候选导入，用户确认后才绑定到项目。

商业化进入路线：

1. 私有资源包导入/导出：先支持本地 `.json` 资源包。
2. 团队私有库：账号内分享，不公开售卖。
3. 审核制公开市场：加入审核、投诉、下架和版本冻结。
4. 收费与分成：最后接入支付、订单、退款、税务和创作者收益。

## 7. 知识库与语义搜索路线

知识库应先本地化，再考虑云端扩展。

### 7.1 本地知识库

本地知识库索引来源：

- 项目设定、人物、小传、章节摘要、剧本摘要、分镜 Prompt。
- 项目级 Skills、Agent 方案、模板运行记录。
- 样本库抽象结构、创作卡片和节奏曲线。
- 用户显式导入的参考文档摘要。

索引规则：

- chunk 保存来源类型、来源 id、标题、摘要、更新时间和可见范围。
- embedding 可由用户选择本地模型或 OpenAI-compatible provider 生成。
- 检索结果必须显示来源，不把不可见来源混入 AI 上下文。
- 样本文档默认只索引抽象结构，不索引长段原文。

### 7.2 云端知识库

云端知识库只能在用户开启后同步：

- 项目级私有索引：只服务当前用户账号。
- 团队共享索引：需要角色权限和下载/复制限制。
- 公共知识资源：只允许原创或授权的模板、规范、抽象案例，不允许用户项目正文默认公开。

云端语义搜索必须有来源引用、权限检查、删除重建机制和费用预估。AI 生成前仍应进入上下文透明面板，由用户确认哪些检索结果会被引用。

## 8. 架构草图

```txt
Desktop SQLite
  ├─ Sync Queue
  │   ├─ Project snapshots
  │   ├─ Mobile inspiration drafts
  │   ├─ Asset manifests
  │   └─ Conflict records
  ├─ Local Knowledge Index
  │   ├─ Source metadata
  │   ├─ Redacted chunks
  │   └─ Embeddings
  └─ Marketplace Import Cache
      ├─ Resource package metadata
      ├─ Version lock
      └─ User adoption status

Cloud API
  ├─ Account and device registry
  ├─ Encrypted project snapshot storage
  ├─ Marketplace registry and review queue
  ├─ Private/team knowledge indexes
  └─ Billing and usage ledger
```

桌面端需要保留离线可用能力。云端失败时，用户仍应能打开项目、编辑正文、运行本地配置的 AI provider、导出项目包，并查看上次同步状态。

## 9. 分阶段路线

| 阶段 | 目标 | 交付 | 发布门槛 |
| --- | --- | --- | --- |
| E0 | 当前状态固化 | LM2-21 移动 JSON/Markdown 导入；本文件定义生态边界 | 不改变本地优先 |
| E1 | 本地资源包 | 模板/Skills/Agent 方案本地导入导出；资源包 schema | 单测、项目包兼容、人工导入检查 |
| E2 | 本地知识库 | 本地 chunk/embedding 索引和可解释检索 | 上下文透明面板可显示检索来源 |
| E3 | 移动草稿箱 | 账号内只同步移动灵感卡片和草稿状态 | 冲突队列、删除机制、隐私说明 |
| E4 | 项目快照同步 | 加密项目包快照、资产清单同步、手动恢复 | 正文冲突 diff 预览，不静默覆盖 |
| E5 | 私有资源库 | 团队或个人私有资源包分发 | 权限、版本锁、撤回机制 |
| E6 | 公开资源市场 | 审核制公开资源市场 | 审核、投诉、下架、支付和退款闭环 |
| E7 | 云端知识库 | 私有/团队知识库语义搜索 | 权限、费用估算、来源引用、删除重建 |

## 10. 验收口径

后续任何进入实现的生态能力必须明确：

- 会同步哪些数据，明确不会同步哪些数据。
- 是否包含正文、样本、资产二进制、AI run 输入输出或密钥。
- 冲突如何保存、展示和采用。
- 云端失败时桌面端如何继续工作。
- 资源是否可撤回、可删除、可导出。
- 语义搜索结果如何进入上下文透明面板。
- 涉及付费时订单、退款、资源审核、下架和用户资产可用性如何处理。
