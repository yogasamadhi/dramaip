# LM5-03：主内容导入

项目工作台现提供“导入正文”入口，供拥有内容使用权的用户将小说主稿或漫剧剧本带入本地项目。

- 支持 TXT、Markdown、DOCX、EPUB，以及明确包含 `episodes` / `scripts` 的结构化 JSON 剧本。
- 导入前必须确认权利；原文件仅在本机主进程读取，不上传、不改写，也不会保存原始路径。
- 导入向导会展示识别类型、章节/分集/场景摘要、空章与超长章提示、重复项和预计新建/修改数量。小说正文可在写入前编辑、拆分、新增或删除章节。
- 默认策略为“新建”，绝不覆盖。用户选择合并或覆盖时，必须二次确认；对已有章节/剧本的修改先保存 `manual_checkpoint` 内容版本。
- 写入章节、分集、剧本和场景使用同一 SQLite 事务。解析失败、取消或任意写入失败都不会留下部分数据。
- 未知 JSON 只会作为草稿文本导入，不会猜测剧本结构。导入后只提示后续故事圣经建议，不会自动采用人物、大纲或设定。

边界：不支持 PDF OCR、DRM 绕过、付费内容抓取或版权证明；单文件上限 30 MB，解压条目上限 8 MB，文本预览上限 1,500,000 字符。
