# LM5-05：故事圣经变更包

## 用户流程

1. 完成并保存章节后，在“故事圣经”选择“为本章生成建议”。
2. 系统先显示 token/费用预估；费用没有配置时明确显示“费用未知”。
3. AI 只生成草案，集中展示章节记忆、人物/关系/秘密、事件时间线、伏笔与视觉连续性的新增或回收建议。
4. 用户点击“一次采用”后，相关实体在同一 SQLite 事务内写入；任一项失败会整体回滚。
5. 用户可撤销该变更包，撤销只删除该包创建的记录，不改动原章节或之前的手写故事圣经。

## 自动建议与过期

- 自动建议默认关闭。开启后，正文停止编辑并稳定保存 1.5 秒才加入建议队列；不会在键入时调用模型，也不会自动采用。
- 正文再次变化后，旧变更包会标记为“已过期”，同时显示故事圣经与下游诊断的回填提醒。
- 长篇可按当前过期范围重新排队；单项支持暂停、恢复、跳过、失败明细与重试。

## 兼容与安全

- 既有“记忆 / 人物状态 / 时间线 / 伏笔 / 视觉设定”页面继续可用。
- 新变更包只追加自身产生的记录，不静默覆盖用户已有设定；找不到人物或伏笔目标时作为冲突阻止采用。
- 迁移只新增 `story_bible_*` 表与索引；回滚应用版本不会删除已有章节或故事圣经实体。
