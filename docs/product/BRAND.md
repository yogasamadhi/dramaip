# 尽意 DramaIP 品牌与文案规范

> **尽作者之意，成万象之作**
>
> 本地优先的 AI IP 创作工作台

## 品牌含义

“尽意”首先是尊重作者：理解作者真正想表达的主题、情绪、人物与世界，而不是用模型的偏好替代创作判断；其次是帮助作品抵达更丰富的形态，让同一个创作意图可以在小说、剧本、分镜、声音与影像之间延展。

“尽作者之意，成万象之作”是品牌主张。“尽作者之意”说明产品与 AI 的角色是理解、协作和实现；“成万象之作”表达作品形态与想象空间的开放性。两句共同强调：作者拥有意图与最终决定权，AI 负责扩大实现能力。

## 标准写法

| 用途       | 标准文案                      | 说明                                       |
| ---------- | ----------------------------- | ------------------------------------------ |
| 中文主品牌 | `尽意`                        | 适合图标、紧凑导航和中文语境中的简称       |
| 完整品牌名 | `尽意 DramaIP`                | 应用标题、官网、下载页和正式文档的首选写法 |
| 品牌主张   | `尽作者之意，成万象之作`      | 首页首屏、品牌介绍和发布物料使用           |
| 产品定位   | `本地优先的 AI IP 创作工作台` | 首次介绍产品时使用                         |

首次出现时使用“尽意 DramaIP”，后文可按语境简称“尽意”或使用稳定英文名“DramaIP”。不再把 `DramaIP Studio` 作为面向用户的主品牌名；`Studio` 仍可用于套餐名、工作区类型或技术 Profile 等有明确含义的场景。

## 文案层级

面向新用户的页面按以下顺序表达，避免把品牌名、口号和功能说明挤成一句话：

1. 完整品牌名：尽意 DramaIP。
2. 品牌主张：尽作者之意，成万象之作。
3. 产品定位：本地优先的 AI IP 创作工作台。
4. 场景说明：根据页面补充小说、剧本、分镜、影像生产或本地数据边界。

功能页不必反复展示口号。导航栏保留品牌名，页面标题直接说明用户当前要完成的任务，例如“小说写作”“导演看板”“审核交付”。

## 语气与原则

- 以创作者为主体，使用“帮助创作者”“由你确认”“最终采用权”等表达，不把 AI 描述为作品的作者。
- 强调本地优先、过程可追溯、变更可确认，不把可选云能力表述为默认上传或自动接管。
- 描述已经存在的能力和清晰边界，避免“全自动成片”“一键爆款”等无法验证的承诺。
- “IP”表示可持续发展的创作世界与内容资产，不只指短剧，也涵盖小说、剧本、分镜、声音和影像等作品形态。

## 技术标识边界

品牌升级不改变兼容标识。包名与作用域（如 `@dramaip/*`）、Java 包名、数据库与环境变量、`X-DramaIP-Contract-Version`、`dramaip` URL scheme、API 路径、文件格式、遥测事件和既有持久化键继续使用 `DramaIP` 或 `dramaip`。这些名称是稳定技术契约，不应为了界面文案统一而迁移。
