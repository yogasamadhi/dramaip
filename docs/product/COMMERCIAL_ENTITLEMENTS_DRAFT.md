# 创作成果与套餐权益映射草案

状态：权益／定价建议仍未生效；本地Web展示已按真实字段修正，未部署。更新日期：2026-10-07。

本文供产品、Web 和 Billing 维护者评审，说明如何按小说、改编、质量、交付与协作结果组织套餐。它不是价格表、已上线权益或购买承诺，不修改当前套餐、支付、额度、订阅和本地功能。实际可售套餐仍由当前环境的 Billing API 返回；仓库代码不能证明生产环境已配置或发布。

建议保留本地作品与基础创作控制权，把付费价值放在可核验的服务、交付和协作容量上。独立小说作者不必购买改编或媒体能力才能完成稿件；改编作者也不必先写小说或生成视频。是否采用本建议，需后续真实用户任务、服务成本与维护者决策。

## 当前代码边界

Desktop 与 Platform 是独立产品。Desktop 的正式内容、候选、版本和保存回执由本地 Runtime 的领域所有者维护；Platform 的套餐、订单、订阅及云端权益另有服务所有者。本草案不建立跨产品依赖，不把 Desktop Profile、插件、模型或计划任务数直接映射为付费档位。

当前 Web 按 `free`、`creator`、`studio`、`enterprise` 排列显示名称。Billing 从实际 `billing.plans` 活跃记录读取金额、币种、周期、额度、模型等级、购买模式和权益；客户端将其转换为 Plan。显示代码中的四个名称不证明当前环境必有四个可购买套餐。金额和资源数量应读取服务端，不从历史 SQL、示例或本文补造。

现有客户端权益结构包括席位、BYOK、离线审片、高级导出、云审片容量与保留天数及私有网关，共八个字段。它没有单独的“小说规划”“整季方案”“文学质量通过”、画面标记或权限分级开关。SDK 解析缺失或无效权益时返回禁用值，不代表已购买，也不能借静态官网文案解除服务端限制。

## 建议的套餐分工

下表是价值表达建议，不是新的授权规则。档位名称沿用当前展示代码；不新增 SKU，不分配价格、token、席位或存储数量。

| 当前展示名称 | 建议优先说明的用户结果                               | 不能据此承诺                                   |
| ------------ | ---------------------------------------------------- | ---------------------------------------------- |
| Free         | 保留本地稿件、版本与采用权；从小说或真实已有素材开始 | 免费云推理、无限上下文、已取得内容授权         |
| Creator      | 独立作者与编剧的连续创作、叙事复核和专业交付需要     | 保证文学质量、保证投稿录用、包含视频费用       |
| Studio       | 小型工作室的正式版本审阅、席位与可选云审片           | 自动上传本地原稿、无限容量、自动发行合规       |
| Enterprise   | 按约定部署的私有网关、容量、席位与数据治理           | 未配置网关已可用、默认访问私人正文或供应商凭据 |

小说、改编和质量是用户选择的工作目标，不应另立互斥套餐迫使作者迁移项目。基础稿件读取、作者编辑和现有版本恢复不应因订阅失效而被锁定；这是沿用产品定位的建议约束，不是本文新增了过期账号验收。

## 变更前的证据与确认

产品与 Billing 维护者应先确认：哪些服务真的受权益控制、是否已发布、未知字段如何禁用、既有用户与历史作品如何兼容，以及升级降级怎样影响尚未结束的任务。本次本地阅读没有访问运行中的 Billing 服务，不能确认当前环境的活跃套餐、商户配置、实际账号权益或价格。

后续变更应分别取得以下证据，而不是用一个付费按钮或受控模型输出代替：

1. 两类用户的任务证据：独立小说采用与稿件交付、改编正式链与内部包交付；未完成和放弃同样记录。
2. 实际 reported usage、真实费用回执与服务成本；token 估算、试制风险和账单未知分别表达。
3. Desktop 的订阅过期、离线、导出与恢复检查，以及 Platform 的升级降级、重复支付通知、退款、额度失败与权限检查；不合并两产品的发行结论。
4. 维护者确认拟售权益、迁移方案、价格、条款、客服说明与发布范围，再由各产品独立实施和验收。

这些是待取得的条件，不是本轮完成记录。本草案不改变支付渠道、创建订单、写数据库、开通账号或调用外部模型。

## 本地评审步骤

先用同一份任务脚本让小说作者和改编团队各自选取必要结果，记录必须保留、实际使用、可接受增值与拒绝原因。不要把是否愿意购买媒体当作小说作者的完成指标。随后把证据回填到套餐建议，而不是先指定价格再寻找支持结果。

每项拟售权益应记录产品所有者、真实 API 字段或“尚无字段”、当前验证范围、未知项、过期行为、兼容影响和必要批准。尚未实现的权益只能留在内部建议，不能同步成官网“支持”标签。本文评审通过也不自动授权迁移、支付或发布。
