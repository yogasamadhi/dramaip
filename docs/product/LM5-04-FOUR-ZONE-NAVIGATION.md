# LM5-04：四区任务导向工作台

项目工作台默认按用户任务收束为四个一级区域：

- 内容：项目概览、正文、人物、大纲和授权内容导入。
- 故事圣经：章节记忆、人物状态、视觉设定、时间线、伏笔与一致性检查的聚合入口。
- 制作：第一季、分集剧本生产与行动中心。
- 交付：投稿包、完整项目包和执行记录。

默认导航只显示当前任务所需入口，并隐藏 Agent、底层记忆和分析术语。用户可在侧栏开启“显示高级功能”，恢复所有原有页面；`?section=` 的旧链接保持原样可访问。新增聚合入口使用 `section=story-bible`、`action-center`、`production` 和 `delivery`，不会迁移或删除任何项目数据。

项目概览增加“当前结果 / 主要下一步 / 制作预算”摘要。窗口缩窄时仍保留四区下拉导航、键盘焦点和深链历史；现有全局搜索与命令面板继续作为快速发现入口。
