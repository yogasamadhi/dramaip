# 尽意 DramaIP 创意竞争力系统

本文是[产品定位](./POSITIONING.md)下的横向能力说明。创意竞争力系统服务故事/IP 权威资产、小说母本和分集改编，不是独立的公共语料产品，也不改变“面向 AI 短剧与漫剧的本地优先 AI 编剧与 IP 改编工作台”这一当前定位。

尽意 DramaIP 把“有意思的内容”建模为可追溯、可实验、可采用的创意资产，而不是一批原文。系统由灵感空间、创意语料网络、个人创意指纹、创意实验室、项目知识图、IP 数字孪生、AI 编剧室和原创性账本组成。

小说写作是可独立完成的一等能力：实验与评议应尊重作者的文风、视角和表达目标，不默认把长篇改成短剧或要求每章反转。改编约束只在用户选择该目标时生效；系统构成说明不替代各端实现与发布验收记录。

## 产品边界

- Web 负责无项目的灵感对话、公共语料检索、私人收藏、三档实验和独立授权的创意指纹；Desktop 负责故事母本、小说、改编剧本、因果推演、伏笔与认知检查、编剧室和生产交付。
- 公共语料跨端共享版本；Desktop 只接受 Ed25519 验签成功的离线快照。私人语料、指纹、对话和实验不自动跨端同步。
- `dramaip-project-package` schema v4 是显式跨端桥梁，只复制用户确认的简报、卡片、抽象语料、因果边和脱敏谱系。
- 自动长期记忆与个人创意指纹是两项独立授权。指纹只学习明确采用、拒绝、评分、修改或保存的结果，不扫描未采用对话和项目正文，也不用于平台训练。

## 创意资产与来源

资产类型覆盖梗、喜剧机制、对白模式、人物与关系钩子、冲突、反转、场景、世界规则、风格和社会观察。每项记录触发条件、抽象机制、情绪效果、适用场景、风险和新鲜度。

谱系关系固定为 `collected_from`、`inspired_by`、`derived_from`、`generated_from`、`adopted_from` 和 `quoted_from`。原创性检查展示需要人工复核的相似区段、撤回来源、短引用和过度依赖证据，不提供抄袭、侵权或法律安全结论。

## 实验、模拟与采用

- 新鲜度、情绪钩子和观众模拟是创作参考，不是实测受众留存、爆款概率或商业收益预测；真实模型评价与真人任务测试分别保存证据。
- 创意实验固定给出 `conservative / balanced / wild` 三档，比较新鲜度、连贯性、情绪钩子、受众惊喜、制作可行性和相似度风险。只有用户作出采用、并列或全部拒绝后，授权中的创意指纹才会更新。
- 项目知识图保存人物、事件、秘密、规则、地点、组织、资源、关系和已采用灵感及其因果边。情景模拟先运行确定性冲突检查，再把模型推断单独标示；模拟本身不修改权威项目数据。
- IP 数字孪生是可重建的只读投影。来源变化会将旧快照标为 stale，不静默覆盖，也不进入项目包。
- AI 编剧室默认由一个用户选定模型完成六个相互隔离角色的评议和主编整合；多引擎盲测仍需用户主动开启。只有勾选建议才能进入 Preview/Commit。

## 安全与隐私

公开网页采集默认关闭，遵守 robots、站点规则、请求限速和下架要求，不绕过登录、付费墙、验证码或反爬。正文应用层加密暂存不超过 7 天；长期只保留来源元数据、内容哈希、至多 500 个 Unicode 字符的短摘录和抽象机制。Admin 只能治理公开来源，不能读取私人收藏、对话、记忆或创意指纹。
