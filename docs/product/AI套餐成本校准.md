# AI 套餐与成本校准基线

本基线将 `billing.plans` 的月度 token、上下文上限与 RPM 关联到可重复计算的典型云端
工作流。它不是历史套餐事实；购买时的套餐权益仍由 LM3-11 的订单、订阅与 quota account
快照保存。

| 工作流步骤 | 输入 token | 输出 token | 单次 token |
| --- | ---: | ---: | ---: |
| 故事前提与人物钩子 | 1,200 | 800 | 2,000 |
| 分集大纲 | 6,000 | 4,000 | 10,000 |
| 单场景扩写 | 12,000 | 8,000 | 20,000 |
| 质量复写 | 8,000 | 4,000 | 12,000 |

一条“前提 → 大纲 → 3 个场景 → 复写”的参考链为 `2,000 + 10,000 + 3 × 20,000 +
12,000 = 84,000` tokens。套餐基线（对应当前 seed）如下：

| 套餐 | 月额度 | 参考链/月 | 上下文上限 | RPM |
| --- | ---: | ---: | ---: | ---: |
| free | 10,000 | 0.12 | 32,000 | 5 |
| basic | 500,000 | 5.95 | 64,000 | 20 |
| pro | 2,000,000 | 23.81 | 128,000 | 60 |
| premium | 10,000,000 | 119.05 | 256,000 | 120 |

运营在变更套餐或模型路由前必须用实际 Provider cost log 按相同公式复算：

```text
链路 token = Σ(prompt_tokens + completion_tokens)
月参考链数 = monthly_token_quota / 链路 token
平台成本 = Σ(input_tokens × input_price + output_tokens × output_price) / 1,000,000 × 汇率
```

配置价格时优先使用 `AI_PROVIDER_<PROVIDER>_<MODEL>_*`；provider 级 fallback 仅适用于
运营明确确认同一 provider 下所有允许模型计价相同的场景。未知价格或汇率会被网关保守拒绝，
不能以零成本继续开放平台 API Key。
