# 用户手册

本文面向日常使用者，说明如何安装启动、配置模型、完成从小说到短剧视频任务的主流程，以及如何备份、导入导出和导出诊断信息。

## 安装与启动

### 从源码启动

```bash
pnpm install
pnpm rebuild
pnpm dev
```

- `pnpm rebuild` 会把 better-sqlite3 编译到 Electron ABI；首次安装或刚跑过 `pnpm test:db` 后建议执行。
- 如果从其它 Electron 工具的终端启动时报 `Cannot read properties of undefined (reading 'whenReady')`，使用 `env -u ELECTRON_RUN_AS_NODE pnpm dev`。
- 所有项目数据默认保存在本机 Electron `userData` 目录下的 `studio.db`，不会上传到云端。

### 打包版启动

安装打包产物后直接打开应用。首次启动会自动创建数据库、应用版本化迁移，并创建启动备份。

## 首次配置模型

进入「设置 → 模型配置」。

1. 填写配置名称、Provider、Base URL、API Key 和模型名。
2. 保存后设为默认模型。
3. 点击连接测试，确认模型能返回响应。
4. 可在「任务模型绑定」中给写作、改编、剧本、分镜、创意诊断等任务组指定不同模型。
5. 可在同页设置单次/每日 token 或费用限制；「用量统计」页面可查看模型和任务组消耗。

API Key 只保存在本机。系统安全存储可用时会加密保存；不可用时需在设置页显式允许明文降级。

## 基础创作流程

1. 在首页新建项目，填写短剧类型、目标受众、核心爽点和梗概。
2. 在项目工作台创建或生成章节、大纲、人物卡。
3. 使用章节记忆、人物状态、事件线、伏笔和视觉档案维护长篇一致性。
4. 在创意诊断区运行新鲜度、反套路、质量闸门、观众模拟等检查。
5. 新建改编项目，把小说转换为分集大纲。
6. 进入剧本工作台生成每集剧本，并拆分场景。
7. 进入分镜工作台拆分镜头、生成镜头 Prompt、负面 Prompt 和首帧 Prompt。
8. 进入视频生成页，为镜头提交视频任务并对比结果。

「完整工作流模板」可把质量闸门、分集、剧本、分镜和视频任务草稿串成流水线。建议在每个暂停点人工检查后继续。

## 资产引用

- 人物视觉档案和镜头 Prompt 都可以填写参考图 URL 或本地路径。
- 本地路径会进入资产账本；如果文件后来被移动或删除，界面会显示缺失状态。
- 视频任务会自动收集镜头参考图和角色视觉档案参考图作为参考图输入。
- 视频结果和封面会记录远端 URL 和本地归档路径，便于后续排查和项目整理。

## 备份与恢复

进入「设置 → 数据与备份」。

- 应用启动时会自动备份 `studio.db`，默认保留最近 7 份。
- 可点击创建手动备份。
- 恢复备份前，应用会先创建一份当前数据库安全备份；恢复成功后会刷新应用。
- 备份列表会显示文件名、类型、时间、大小和本机路径。

建议在大规模生成、导入项目包、恢复旧项目之前先手动创建备份。

## 项目包导入导出

### 导出

在项目工作台点击「导出完整项目包（.sdnspkg）」。

- 项目包是 JSON 格式，包含项目、人物、章节、改编、剧本、场景、创意诊断、工作流记录等结构化数据。
- 当前界面默认导出结构化数据，不内嵌本机二进制素材；远端链接和本地资产状态会按资产清单策略处理。

### 导入

在首页点击「导入项目包」，选择 `.sdnspkg` 或兼容 JSON 文件。

- 导入前会显示项目包版本、项目名和数据规模。
- 导入会创建一个新项目，重新生成 id，并重映射内部外键。
- 来自其它机器的本地绝对路径不会直接复用；有远端 URL 的资产会作为远端引用，没有可用路径的资产会标记为缺失。

## 视频生成配置

进入「设置 → 视频生成设置」。

- `Mock`：不调用真实平台，适合验证全流程。
- `OpenAI Sora`：使用 OpenAI Sora 视频接口。
- `自定义（OpenAI 兼容）`：适配 OpenAI-compatible 风格的视频服务。
- 即梦、可灵、海螺、Runway、Pika 当前保留独立适配槽位；如果平台接口未实现，会返回明确错误。

配置完成后设为默认视频 Provider。视频生成页会优先使用默认 Provider；如果未配置，会提示先进入视频生成设置。

## 日志与诊断

进入「设置 → 诊断」。

- 可导出诊断包，包含版本、系统信息、迁移版本、最近错误和脱敏日志。
- 默认不包含正文内容和密钥。
- 只有在需要排查 AI 上下文问题时，才勾选包含内容；导出前请确认文件可安全分享。

页面崩溃恢复界面也提供导出诊断入口，可在白屏或异常时保留现场信息。
