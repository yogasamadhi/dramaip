# 使用说明

DramaIP 将小说写作、剧本开发与 IP 改编放在同一个桌面工作区中。当前源码版本为 3.0 alpha；从源码启动的方法见 [开发指南](DEVELOPMENT.md)。

## 创作流程

1. 创建项目，填写创作目标与简介，或导入已有作品。
2. 小说项目可维护章节、人物、世界设定与故事规划，独立完成写作和稿件整理。
3. 需要改编时，选择明确的来源，逐步开发改编方案、剧本和分镜。
4. 使用 AI 提出候选内容后，比较修改并决定是否采用。保存草稿和采用正式版本是不同操作。
5. 按项目需要整理、导出作品或交付资料。媒体生成需要单独配置相应的服务商。

## 配置模型

在应用设置中配置所需的模型服务商、接口地址和密钥，再选择对应模型。可用模型和能力取决于服务商配置。远程模型请求需要网络连接，并可能产生服务商费用。

## 本地数据

默认数据目录为 `~/.dramaip`，可通过 `DRAMAIP_HOME` 环境变量指定其他位置。

| 相对目录               | 内容                        |
| ---------------------- | --------------------------- |
| `profiles/`            | Profile 配置                |
| `storage/`             | 业务数据库与存储            |
| `desktop/credentials/` | 本地凭据与密钥文件          |
| `desktop/electron/`    | Electron 用户数据和会话缓存 |
| `logs/`                | 运行日志                    |

备份或迁移时，退出应用后保存整个数据目录，包括凭据密钥文件。向他人提供问题日志时，先检查是否包含正文、密钥或其他私人信息。
