# LM5-08 版权与授权资产台账

项目概览中的“版权与授权台账”把原稿、人物/选角参考、声音、场景、封面、视频和生成结果逐项列出。

- 状态始终明确为：已核验、已声明、未知、已过期或受限；“已声明”不会被当成已授权。
- 授权证明通过选择文件复制到项目受控资产库，记录 SHA-256；证明正文、绝对路径和媒体二进制不会进入诊断包或默认项目包。
- 最终交付预检按目标平台、地区和日期检查状态、证据、期限和用途范围。未知、过期、受限、范围不符或证据丢失均会阻止交付，但不阻止草稿工作。
- 项目包只保留台账清单、证据引用和 hash。导入到新机器后，证据必须由用户显式重新定位；不会静默携带证明文件。
- 已登记的人物或选角参考用于视频生成时，主进程会要求已核验的生成授权；选角参考还需要肖像授权，不能靠文本勾选绕过。

本功能提供工程内的权利信息与阻塞提示，不替代法律意见或自动判断授权有效性。
