# 用户手册

本文面向日常使用者，说明如何安装启动、配置模型、完成从小说到短剧视频任务的主流程，以及如何备份、导入导出和导出诊断信息。

## 安装与启动

### 从源码启动

```bash
pnpm install
pnpm rebuild
pnpm dev
```

- `pnpm rebuild` 会把 better-sqlite3 编译到 Electron ABI；首次安装或刚跑过 `pnpm test:db` 后建议执行。
- 如果从其它 Electron 工具的终端启动时报 `Cannot read properties of undefined (reading 'whenReady')`，使用 `env -u ELECTRON_RUN_AS_NODE pnpm dev`。
- 所有项目数据默认保存在本机 Electron `userData` 目录下的 `studio.db`，不会上传到云端。

### 打包版启动

安装打包产物后直接打开应用。首次启动会自动创建数据库、应用版本化迁移，并创建启动备份。

## 首次配置模型

进入「设置 → 模型配置」。

1. 填写配置名称、Provider、Base URL、API Key 和模型名。
2. 保存后设为默认模型。
3. 点击连接测试，确认模型能返回响应。
4. 可在「任务模型绑定」中给写作、改编、剧本、分镜、创意诊断等任务组指定不同模型。
5. 可在同页设置单次/每日 token 或费用限制；「用量统计」页面可查看模型和任务组消耗。

API Key 只保存在本机。系统安全存储可用时会加密保存；不可用时需在设置页显式允许明文降级。

## 主流程创作

1. 在首页新建项目，填写短剧类型、目标受众、核心爽点和梗概。
2. 进入项目工作台，先看「主流程」区块。它会按设定、人物、大纲、章节、质量闸门、改编、剧本、分镜、视频展示完成状态和下一步入口。
3. 创建或生成章节、大纲、人物卡；章节完成后维护章节记忆、人物状态、事件线、伏笔和视觉档案。
4. 在创意诊断区运行新鲜度、反套路、质量闸门、观众模拟等检查。
5. 将诊断结果转为修稿任务。任务可触发改写预览，确认采用后会生成内容版本，并可再次复检。
6. 新建改编项目，把小说转换为分集大纲。
7. 进入剧本工作台生成每集剧本，并拆分场景。
8. 进入分镜工作台拆分镜头、生成镜头 Prompt、负面 Prompt 和首帧 Prompt。
9. 进入视频生成页，为镜头提交视频任务并对比结果。

创意诊断区的「自动工作流」提供新项目完整体检、章节反套路修稿、改编前质量闸门、视频生成前质量闸门和「小说到视频任务流水线」。建议使用「单步」模式，在每个暂停点人工检查后继续。

## Agent 指挥台

项目工作台左侧有「Agent 指挥台」入口。可以输入自然语言命令，例如修改章节、生成分集大纲、拆分镜头等。

- 系统会先识别目标实体和任务类型，展示执行计划。
- 会写入或高影响修改的任务需要确认；章节改写、分集生成等会进入预览采用流程。
- 如果命令不明确，先补充章节名、集数、场景或镜头范围，再重新执行。

## 上下文透明控制

AI 生成前会打开上下文预览。你可以查看即将发送给模型的项目设定、章节、人物、样本结构、项目 Skills、视觉档案和裁剪说明。

- 固定：强制把某个章节、人物、样本或视觉档案放进本次上下文。
- 排除：明确不让某项材料进入本次上下文。
- 自动：交给系统按任务类型和预算选择。

如果发现 AI 引用了旧设定，优先在上下文预览中排除旧材料或固定新的章节记忆，再重新生成。

## 样本库与拆书

首页或工作区可进入「样本库」。支持导入 `.md`、`.txt`、`.docx` 样本文档。

- 导入后系统会按章节拆分，可在结构不准确时人工修正。
- 结构抽取只保存钩子、爽点、人物关系、反转、悬念、节奏等抽象标签，不把第三方原文写入项目正文。
- 生成的创作卡片会进入灵感台和创意诊断上下文，可用于开局、章节要求或改写方向。

## 灵感台

项目工作台左侧有「灵感台」入口。它会汇总类型模板、样本结构卡、反套路方案、AI 生成的类型化灵感和收藏卡片。

- 卡片可以收藏，并插入项目设定或章节要求。
- 类型化灵感生成会根据题材、受众和短剧方向输出多组方案；创建项目或章节改写前仍需要确认。
- 「导入移动灵感」支持 JSON 或 Markdown 文件。移动端只作为轻量记录入口，导入后仍需在桌面端手动采用。

## 项目 Skills 与 Agent 方案

项目可以维护自己的创作规范和 Agent 方案。

- 项目 Skills 适合保存类型节奏、人物对白、镜头 Prompt、平台交付规范等长期规则。
- 项目 Agent 方案可选择启用的 Agent、主 Agent、绑定 Skills 和任务组模型。
- 这些配置会进入上下文预览，避免隐式 prompt 影响生成结果却不可见。

## 资产引用

- 人物视觉档案和镜头 Prompt 都可以填写参考图 URL 或本地路径。
- 本地路径会进入资产账本；如果文件后来被移动或删除，界面会显示缺失状态。

### 角色与场景生产资产包

- 在项目概览的“角色 / 场景生产资产包”中，把已授权的本地角色、服装、场景和风格素材创建为候选版本，再明确采用。
- 新版本不会覆盖旧集：已经在分镜中锁定的版本只会在上游换版后显示“待确认更新”，需要在该分镜手动改锁。
- 项目包会保留版本和分镜锁的关联，但不携带本机文件；在另一台机器上请重新定位缺失素材并重新核验授权。
- 视频任务会自动收集镜头参考图和角色视觉档案参考图作为参考图输入。
- 视频结果和封面会记录远端 URL 和本地归档路径，便于后续排查和项目整理。

## 备份与恢复

进入「设置 → 数据与备份」。

- 应用启动时会自动备份 `studio.db`，默认保留最近 7 份。
- 可点击创建手动备份。
- 恢复备份前，应用会先创建一份当前数据库安全备份；恢复成功后会刷新应用。
- 备份列表会显示文件名、类型、时间、大小和本机路径。

建议在大规模生成、导入项目包、恢复旧项目之前先手动创建备份。

## 项目包导入导出

### 导出

在项目工作台点击「导出完整项目包（.sdnspkg）」。

- 项目包是 JSON 格式，包含项目、人物、章节、改编、剧本、场景、创意诊断、修稿任务、内容版本、项目 Skills、项目 Agent 方案、灵感台收藏、样本库、视频前置资产和工作流记录等结构化数据。
- 当前界面默认导出结构化数据，不内嵌本机二进制素材；远端链接和本地资产状态会按资产清单策略处理。

### 交付包

除完整项目包外，还可以按业务场景导出：

- 项目工作台：「导出小说投稿包 Markdown（前 10 章）」或「导出小说投稿包 JSON（前 10 章）」。
- 改编工作台：「提案包」或「提案 JSON」，用于短剧项目提案。
- 剧本工作台：「交付包」或「交付 JSON」，用于分集剧本交付。
- 分镜工作台：「分镜包」「分镜 JSON」「分镜 CSV」，用于镜头 Prompt 和制作流转。

### 导入

在首页点击「导入项目包」，选择 `.sdnspkg` 或兼容 JSON 文件。

- 导入前会显示项目包版本、项目名和数据规模。
- 导入会创建一个新项目，重新生成 id，并重映射内部外键。
- 来自其它机器的本地绝对路径不会直接复用；有远端 URL 的资产会作为远端引用，没有可用路径的资产会标记为缺失。

## 视频生成配置

进入「设置 → 视频生成设置」。

- `Mock`：不调用真实平台，适合验证全流程。
- `OpenAI Sora`：使用 OpenAI Sora 视频接口。
- `海螺 Hailuo`：使用 MiniMax 官方异步接口；填写 Key 后仍需显式开启生产渠道才可提交，结果会先归档到本机。当前只支持停止本地跟踪，不会取消平台端任务。
- `阿里云百炼 Wan`：使用 Wan 官方异步接口；填写同地域 Key 后仍需显式开启生产渠道才可提交。成功结果会立即归档到本机；只有仍在排队的任务可由平台远端取消，运行中的任务会保留可查询状态。
- `自定义（OpenAI 兼容）`：适配 OpenAI-compatible 风格的视频服务。
- 即梦、可灵、Runway、Pika 当前保留独立适配槽位；如果平台接口未实现，会返回明确错误。

配置完成后设为默认视频 Provider。视频生成页会优先使用默认 Provider；如果未配置，会提示先进入视频生成设置。

## 日志与诊断

进入「设置 → 诊断」。

- 可导出诊断包，包含版本、系统信息、迁移版本、最近错误和脱敏日志。
- 默认不包含正文内容和密钥。
- 只有在需要排查 AI 上下文问题时，才勾选包含内容；导出前请确认文件可安全分享。

页面崩溃恢复界面也提供导出诊断入口，可在白屏或异常时保留现场信息。
