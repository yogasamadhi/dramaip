# DramaIP Desktop v3 使用指南

从“项目首页”创建项目，再进入项目工作区添加章节。章节保存使用整数版本检查；编辑器版本过旧时会提示刷新，不会覆盖较新的内容。

当前顶部导航为“项目 / 创作 / 改编 / 制作 / 审核交付 / 数据洞察 / 搜索 / 任务 / 设置”。“项目”首页支持按标题和类型创建项目、创建示例项目以及导入项目包；其他入口按内容域提供现有工作区。所有资料都由本地 HTTP Server 保存。选择本地文件时，Renderer 只会获得短期 capability token，不会获得可提交给业务接口的绝对路径。

当前界面仍以多个工作区和全局助手侧栏为主，不应将其误解为已经完成的“生产驾驶舱”或“单一下一步”体验；这些改造由后续 Loop 交付。

## 从首页开始项目

首页的三个入口都会保存一份可编辑的生产简报：创建路径、内容形态、目标受众与平台、单集时长、计划集数、画幅和视觉方向。它们不会要求先选择智能引擎、任务、模型或服务商。

- **从灵感开始**：保存故事构思和生产简报，再进入项目继续补全。
- **导入原著**：先创建有明确生产目标的项目，随后自动打开本地文件预览。只有核对预览并确认拥有使用权后，章节、剧本和场景才会写入；取消预览不会写入内容，项目可继续留作待导入简报或移入回收站。
- **直接导入 / 粘贴剧本**：粘贴内容会保存为“第 1 集剧本草稿”；选择文件时使用与原著相同的 capability-token、预览和权益确认流程。

生产简报会随项目包导出和导入。旧项目没有这份简报时仍可打开和再次导出，不会被自动补写或修改。

## 模型服务商

“设置”页面最上方是“模型服务商”。选择 OpenAI、Anthropic、Google Gemini、DeepSeek、Kimi、MiniMax、Mistral AI、xAI Grok 或 OpenRouter 后，再从联动列表选择模型并填写接口密钥即可；接口地址和协议由应用随版本内置。

需要连接兼容接口、私有网关或目录外模型时，选择“其他（全部手动填写）”，手动填写服务商名称、服务类型、模型名称、接口地址、协议和接口密钥。常用服务商连接成功后，应用会把账号实际可用的模型合并到模型列表中。

接口密钥通过桌面安全凭据接口保存，业务数据库只记录凭据引用。编辑已有配置时可以不填写密钥，以继续使用原密钥；若本机凭据存储不可用，应用不会退回明文保存。

模型目录随桌面版本发布并显示最近核对日期。每次提升应用版本都必须重新核对官方目录、模型标识和下线公告，否则发布检查不会通过。

## 智能引擎

在“设置 → 智能引擎”中查看 OpenCode、Codex 和 LangGraph.js 的状态、版本与认证方式，并设置全局和项目默认引擎、模型。Codex 始终显示“测试版”，可使用安全保存的 API Key、ChatGPT 浏览器登录或设备码登录。

智能助手侧栏允许每次任务重新选择引擎、模型和任务。失败只会显示所选引擎的中文错误，不会自动改用其他引擎。任务详情展示正式输出、工具调用、Token、费用、中断和恢复。

三引擎盲测必须由用户主动发起。开始前会显示三次调用的预估 Token 和费用说明，可选择“各引擎推荐配置”或“三个引擎使用同一模型”。评价前只显示“方案一 / 方案二 / 方案三”，评价后才揭示引擎。

## 内容修改与远程生成

写作、角色、大纲、剧本、场景、镜头和 Story Bible 的智能修改只生成“内容变更预览”。核对差异后点击“确认应用”才会写入正式资料；目标版本变化时会要求重新生成或人工合并。

图片、音频、视频和成片渲染只允许调用厂商 API 或远程部署的 Stable Diffusion API。智能引擎只能建议厂商、模型、参数、提示词和预估费用；用户确认后 Server 才创建远程任务。应用不提供本地小说、图片、音频、视频生成，也不提供本地视频渲染。
