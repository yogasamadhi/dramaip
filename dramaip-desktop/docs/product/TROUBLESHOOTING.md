# 故障排查

遇到问题时，优先确认当前应用是否能打开「设置 → 诊断」并导出诊断包。诊断包默认会脱敏，不包含 API Key 和正文内容。

## 启动与安装

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| `Cannot read properties of undefined (reading 'whenReady')` | 当前 shell 设置了 `ELECTRON_RUN_AS_NODE=1` | 使用 `env -u ELECTRON_RUN_AS_NODE pnpm dev`，或换一个新终端 |
| `better-sqlite3` 相关 native module 报错 | better-sqlite3 ABI 与当前运行环境不一致 | 开发启动前运行 `pnpm rebuild`；跑测试用 `pnpm test:db`，它会自动切回 Electron ABI |
| 安装 Electron 慢或失败 | 网络无法下载 Electron 二进制 | 确认 `.npmrc` 镜像配置可用，或设置本地网络代理后重新 `pnpm install` |

## 模型配置与 AI 失败

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 连接测试失败 | Base URL、API Key、模型名或网络不正确 | 到「设置 → 模型配置」检查配置；确认 Base URL 包含正确 `/v1` 路径；重新测试连接 |
| AI 任务返回空内容或 JSON 解析失败 | 模型未按 prompt 输出结构化结果 | 换更强模型，或在任务模型绑定里给创意/剧本/分镜任务使用更稳定的模型 |
| AI 任务被预算拦截 | 单次/每日 token 或费用限制过低 | 到「设置 → 模型配置」调整预算；到「用量统计」查看消耗 |
| 某类任务一直失败 | 任务绑定了不可用模型 | 在「任务模型绑定」取消该组绑定，先回退默认模型再测试 |
| 生成后内容未写入 | 该任务是预览确认型任务 | 在预览弹窗中确认采用；危险覆写类任务不会直接覆盖正文 |

可到「设置 → 任务监控」查看长任务状态、失败信息、取消或重试任务。需要进一步排查时，在「设置 → 诊断」导出诊断包。

## 主流程、Agent 与上下文

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 主流程卡片一直显示未完成 | 项目缺少该阶段必需数据，如人物、章节、质量闸门、改编项目或剧本 | 按卡片的下一步入口补齐数据；已有数据时刷新项目工作台 |
| Agent 指挥台无法识别命令 | 命令缺少目标章节、集数、场景或镜头范围 | 在命令里写清对象，例如章节标题、目标集数或场景名 |
| Agent 计划生成了但没有写入 | 高影响任务需要预览或二次确认 | 在预览弹窗确认采用；取消采用不会修改正文 |
| 上下文预览缺少关键材料 | 材料尚未创建，或被本次控制项排除 | 先补齐章节记忆、人物、样本或视觉档案；在上下文预览里把关键项改为固定 |
| AI 引用了旧设定 | 旧章节、旧样本或旧人物状态仍在自动上下文中 | 在上下文预览中排除旧材料，固定新的章节记忆或人物状态后重试 |

## 样本库、灵感台与拆书

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 样本文档导入失败 | 文件扩展名、大小或内容解析不符合要求 | 使用 `.md`、`.txt`、`.docx`；先拆成较小文件再导入 |
| 拆章结果不准 | 原文标题格式不统一，或章节分隔不明显 | 在样本库里人工修正章节，再执行结构抽取 |
| 样本卡片没有进入灵感台 | 结构抽取尚未完成，或当前项目未加载对应样本 | 先生成样本结构卡片，再回到项目灵感台刷新 |
| 移动灵感导入失败 | 文件超过 300KB，或 JSON/Markdown 格式无法识别 | 按 [移动灵感导入](../../../docs/product/MOBILE_INSPIRATION_IMPORT.md) 的格式拆分文件；JSON 使用数组或 `items/cards/inspirations/records` 字段 |
| 移动灵感导入后没有改动项目正文 | 移动灵感只会进入灵感台收藏快照 | 在灵感台手动插入项目设定或章节要求，或触发章节改写预览 |

## 视频平台问题

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 提交视频任务提示未配置 Provider | 没有默认视频 Provider | 到「设置 → 视频生成设置」新增 Provider 并设为默认 |
| 真实平台返回未实现错误 | 该平台适配槽位尚未接入真实 API | 使用 `Mock` 验证流程，或使用 `OpenAI Sora` / `自定义（OpenAI 兼容）` |
| 视频状态长时间 running | 平台任务仍在排队或轮询失败 | 在视频生成页点击刷新状态；检查 Provider Key、模型、平台额度和网络 |
| 结果无法本地归档 | 远端 URL 过期、无权限或文件过大 | 保留远端 URL，重新刷新状态；必要时在诊断包中查看归档错误 |
| 参考图没有生效 | 镜头或人物视觉档案未配置参考图，或本地文件缺失 | 在人物视觉档案和镜头 Prompt 编辑器填写 URL/本地路径；确认资产状态不是文件缺失 |

## 备份与恢复

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 备份列表为空 | 应用尚未成功创建自动或手动备份 | 到「设置 → 数据与备份」点击创建手动备份 |
| 恢复后看不到最新内容 | 恢复的是旧备份 | 检查备份时间和文件名；恢复前应用会自动创建当前数据库安全备份 |
| 数据库打不开 | SQLite 文件损坏或 WAL 文件不一致 | 优先用「数据与备份」恢复最近备份；若应用无法启动，保留 `studio.db`、`studio.db-wal`、`studio.db-shm` 后再排查 |

## 项目包导入导出

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 导入被拒绝 | 文件扩展名、大小或 JSON 结构不符合要求 | 使用 `.sdnspkg` 文件；确认文件未被压缩工具或编辑器改坏 |
| 提示项目包版本过高 | 该包来自更新版本应用 | 升级当前应用后再导入 |
| 导入后项目名带「导入」 | 为避免覆盖同名项目 | 这是正常行为，可导入后手动改名 |
| 本地资产显示缺失 | 项目包来自其它机器，本地绝对路径不可复用 | 如果有远端 URL 会保留远端引用；否则重新选择本机素材路径 |

## 交付包导出

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 小说投稿包内容很少 | 项目缺少章节，或前 10 章尚未创建正文 | 先补齐章节正文、简介、标签和质量诊断结果，再重新导出 |
| 短剧提案包缺少分集 | 改编项目没有分集大纲 | 在改编工作台生成或补充分集大纲后导出 |
| 分集交付包缺少剧本 | 分集尚未生成剧本 | 在剧本工作台为对应集生成剧本，再导出交付包 |
| 分镜交付 CSV 为空 | 场景还没有拆分镜头 | 在分镜工作台执行拆镜头并生成镜头 Prompt 后导出 |
| 平台交付被阻断 | 合规 MP4、媒体质检、权利、采用创意候选、封面或人工平台字段未齐 | 按预检 blocker 逐项补齐；不要绕过 AIGC 或权利检查 |
| 语言版本无法采用 | 有未译句、字幕阅读速度过高，或中文母版已变化 | 补齐逐句译文、缩短字幕/延长时长；母版变动后新建或复核语言版本 |

## 本地验证脚本

| 现象 | 常见原因 | 处理方式 |
| --- | --- | --- |
| `pnpm test:db` 在 native rebuild 阶段失败 | better-sqlite3 需要写入本机 Node/Electron 编译缓存 | 确认当前用户可写 npm、node-gyp 和 Electron 缓存目录；修复后重新执行 `pnpm test:db` |
| `pnpm test:e2e` 在 Electron rebuild 阶段失败 | Electron 原生模块缓存不可写或 Electron 二进制不可用 | 先运行 `pnpm rebuild`；确认 Electron 缓存和网络环境可用后重新执行 |
| `pnpm test:e2e` 没有看到 P0 步骤 | smoke 日志被截断或旧构建未更新 | 重新运行 `pnpm test:e2e`，正常日志会输出主流程、Agent 指挥台、拆书卡片、修稿采用、投稿包导出和项目包往返步骤 |
| 真实图片/TTS/视频 sandbox 被拒绝 | 未注入专用 API Key 或未显式授权计费 | 保持 Provider 关闭；由账户所有者在隔离环境按对应 Provider Runbook 注入凭据并执行 smoke，不能使用 Gitee 凭据替代 |

## 日志与诊断

诊断入口在「设置 → 诊断」。

- 默认诊断包包含系统信息、迁移版本、错误统计和脱敏日志。
- 勾选包含内容会带上受限长度的正文/上下文片段，只在可信环境中分享。
- 页面崩溃恢复界面也可以导出诊断包。
- 反馈问题时，请同时说明操作步骤、失败时间、模型/视频 Provider 类型，以及是否刚导入项目包或恢复备份。
