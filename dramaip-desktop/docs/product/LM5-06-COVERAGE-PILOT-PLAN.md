# LM5-06：真实覆盖率与试播编排

本轮把“已有一条记录”从完成信号中移除，改为按本季目标集数及用户选择的 1～3 集试播范围计算。

## 用户可见行为

- 项目概览同时显示全季的分集、剧本、场景、镜头、已选视频覆盖率；例如 20 集目标只有 3 集剧本时固定显示 `3/20`。
- 试播默认是项目 Production Profile 的前 1～3 集。用户可以在创建项目时选择数量；大于 3 的旧值会兼容收敛为 3，不会扩展为整季任务。
- 试播面板显示源版本是否已确认/过期/阻塞、逐阶段依赖、失败任务、下一步、成本未知、版权未知及当前未安装能力。
- 图片资产、配音、剪辑、最终交付、版权与成本账本尚未实现时，界面明确显示“能力未安装/未知”，不会伪造成功、费用或可发布状态。
- 试播剧本批处理在界面和主进程均限制在当前 1～3 集范围。即使调用方绕开前端传入后续集，主进程也会拒绝批处理。
- 试播的剧本、分镜、每集已选视频候选和当前质量闸门通过且无失败任务后，进入显式的人工“通过试播 / 退回返工”暂停点。只有人工通过，用户才能为下一批最多 3 集创建“复制 Profile 的后续计划”。该计划只保存在本地界面偏好中，不创建任何外部或高费用任务。

## 任务中心

从项目总览进入任务中心会自动筛选当前项目，并按剧本、分镜、图片/资产、视频、音频、剪辑、质量和最终交付聚合任务。未安装阶段不显示为“已完成”。

## 真值边界

- “已选视频”仅表示每集至少有一个成功任务的最佳候选；不表示含音频、字幕、剪辑和质检的最终成片。
- 状态计算是只读派生，不删除、不修改章节、剧本、资产或既有任务。
- 质量报告遵循源指纹：源内容变化后立即显示过期，必须重新检查。

## 验证

- 目标覆盖率单测覆盖 `3/20` 剧本与 `1/20` 已选视频的反误报场景。
- 桌面 E2E 冒烟新增了“已有 3 集记录但 24 集目标仍未完成”的断言。
