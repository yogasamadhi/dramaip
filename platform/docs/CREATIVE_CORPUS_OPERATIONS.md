# 创意语料治理与下架手册

语料网络是 [产品定位](../../docs/product/POSITIONING.md) 下的辅助灵感与来源能力，不是独立的内容交易/抓取产品，也不替代作者的小说母本、剧本或采用决定。小说可以独立完成稿件；公共语料开关不是本地创作的前提。抽象机制、相似度和模型实验不等于原创性法律结论或爆款预测，私人正文不自动上传为公共语料。

## 启用顺序

所有能力默认关闭。按以下功能开关逐级启用并在每级观察队列、拒绝率、清理延迟和额度补偿：

1. `CORPUS_CRAWLER_ENABLED=true`：只采集到隔离区，公共搜索仍不可见。
2. Admin 复核来源和权利状态，确认短摘录与抽象机制不含不必要原文。
3. `CORPUS_PUBLIC_SEARCH_ENABLED=true`：只公开 `allowed` 且权利状态允许的条目。
4. `CORPUS_PERSONALIZATION_ENABLED=true`：仅对已单独授权的用户启用指纹排序。
5. `CORPUS_EXPERIMENTS_ENABLED=true`：开放三档创意实验。

## 采集红线

- 只允许 HTTP/HTTPS；DNS 每次请求和每次重定向都重新校验，拒绝内网、环回、链路本地、云元数据及特殊用途地址。
- 不携带用户 Cookie 或凭据，不接受含凭据式查询参数的网址，不绕过登录、验证码、付费墙、robots 或反爬。
- 默认同域追踪 2 层、每域每秒 1 次、最多 5 次跳转、单响应 2 MB；错误 MIME、压缩响应和超限正文直接拒绝。
- 正文使用带密钥版本的 AES-256-GCM 加密，最长保存 7 天。监控 `corpus_source_bodies.expires_at`，清理延迟不得超过一个调度周期。

## 日常治理

Admin 的语料页只显示公开来源元数据、至多 500 字符摘录、队列状态和权利状态。`corpus.read` 可查看；`corpus.write` 可允许来源；域名封禁和来源撤回要求 `corpus.takedown`、现有二次确认和审计记录。

允许来源前检查：站点规则、内容类型、来源标题、短摘录、内容哈希、权利状态和抽象机制。不得把私人收藏、备注、对话、记忆或创意指纹复制到治理界面。

## 投诉与下架

1. 用规范化 URL、域名或 `sourceId` 定位来源，保存投诉单号和处理理由；不要把投诉人敏感信息写入应用日志。
2. 对单一来源执行 takedown；对整域风险执行 block。两者都通过确认与审计流程。
3. 公开条目立即变为 tombstone，清除公开短摘录和临时正文；签名快照下一版携带 tombstone。
4. 私人覆盖层保留用户原创备注和标签，但不再展示被撤回的公共摘录。
5. 纠正后可重新提交、重新提炼和复核，禁止直接恢复旧快照中的正文。

## 发布与故障恢复

- 快照签名私钥只通过 Secret 注入；Desktop 内置对应公钥。签名或下载失败时继续使用上一可信版本。
- 采集失败采用有上限的指数退避并尊重 `Retry-After`。持续失败先停爬虫开关，不影响聊天、私人收藏或现有快照。
- 重点指标：待处理/失败队列、robots 拒绝、域名限速、正文清理延迟、公开条目撤回传播、模型额度 settle/cancel、实验 SSE 恢复。
