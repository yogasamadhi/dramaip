# Official isolated extension fixture

This fixture is compiled by `extension:pack` and exercised by Public Plugin API and Extension Host conformance tests. It contains no Node, filesystem, network, Electron, SQLite, React or HTML dependency.

Extensions support the author-controlled writing and adaptation workflows described in the [project README](../../README.md). This fixture tests the extension API; it does not own authoritative project content or provide unrestricted third-party UI support.
